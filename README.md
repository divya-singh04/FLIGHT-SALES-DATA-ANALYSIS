# ✈️ Flight Data Analysis Dashboard | Power BI

## 📊 Project Overview

This project is an interactive **Flight Data Analysis Dashboard built using Microsoft Power BI**.

The dashboard analyzes flight booking data to understand **revenue performance, airline-wise revenue, destination-wise revenue, flight volume, flight duration, and departure-time trends**.

The objective of this project is to transform raw flight data into an interactive business dashboard that can help users quickly understand key sales and operational trends.

---

## 🎯 Project Objectives

- Analyze total flight revenue and flight volume.
- Compare revenue generated by different airlines.
- Identify major revenue-generating destinations.
- Analyze revenue based on flight duration.
- Analyze the number of flights by departure time.
- Compare total flight prices across airlines.
- Provide an interactive dashboard using airline filters.

---

## 🛠️ Tools & Technologies

- **Microsoft Power BI**
- **Power Query** – Data preparation and transformation
- **DAX** – Measures and calculations
- **Data Visualization**
- **Interactive Slicers & Filters**

## 📈 Dashboard Features

### 1. Revenue by Flight Duration

A column chart showing revenue generated across different flight-duration categories.

This helps identify which flight-duration segments contribute more to overall revenue.

### 2. Revenue by Airline

A donut chart comparing revenue contribution across airlines such as:

- IndiGo
- Vistara
- Go First
- Air India
- SpiceJet
- AirAsia India

### 3. Revenue by Destination

A destination-wise revenue analysis covering:

- BOM
- BLR
- DEL

This helps identify the destinations contributing the largest share of revenue.

### 4. Flight Price by Airline

A horizontal bar chart comparing the total flight price across different airlines.

### 5. Flights by Departure Time

A line chart showing the number of flights across different departure times.

This provides an overview of flight volume throughout the day.

### 6. Interactive Airline Filter

The dashboard includes an airline slicer that allows users to filter the analysis by individual airline.

## 💡 Key Insights
